## Cause (first-hand)

The #833 merge commit's git build died at config validation before building: `dpl_G9WWZNqBJFrfw6jaFspsCgDP4mJu`, `errorMessage: The vercel.json schema validation failed with the following message: ignoreCommand should NOT be longer than 256 characters`. run-003's gates (JSON parse / invariant / YAML safe_load) did not include a length assert — this run adds it.

## Fix

`ignoreCommand` prefix compacted to `case "$VERCEL_GIT_COMMIT_REF" in main|"") ;; *) exit 0;; esac;` — total command **217 chars**. Semantics identical to run-003's design: non-main refs skip; `main` AND unset fail open into the run-002 diff gate, whose pathspec list is preserved byte-exact as the suffix. The `git cat-file -e HEAD^ || exit 1` guard is dropped as redundant: with `HEAD^` missing, `git diff --quiet HEAD^ HEAD` exits 128 — the same non-zero → build outcome.
