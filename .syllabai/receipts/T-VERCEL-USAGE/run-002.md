## Root cause

The run-001 `ignoreCommand` ran `git diff --quiet HEAD^ HEAD -- apps/hub packages/ …`. **The command executes with cwd = the project Root Directory (`apps/hub`), not the repo root** — there, the `apps/hub` and `packages/` pathspecs match nothing, the diff is always empty, `--quiet` exits 0, and Vercel's contract (exit 0 = ignore) skips **every** build. No apps/hub change — including the patch itself — could ever deploy again.

## Fix of record (this commit)

`apps/hub/vercel.json`:

```
git cat-file -e HEAD^ 2>/dev/null || exit 1; cd "$(git rev-parse --show-toplevel)" && git diff --quiet HEAD^ HEAD -- apps/hub packages/ package.json bun.lock bunfig.toml turbo.json tsconfig.base.json
```

- `git rev-parse --show-toplevel` re-roots the diff at the repo top regardless of the caller's cwd.
- `git cat-file -e HEAD^ || exit 1` forces a BUILD when the parent is unavailable (shallow/historyless edge) — fail-open toward freshness, never fail-closed toward a frozen site.
