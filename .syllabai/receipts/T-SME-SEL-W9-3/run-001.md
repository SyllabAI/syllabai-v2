## The set-class law of record (the tranche-3 wrinkle)

b-16's 65 corpus sets are **SyllabAI past-paper sets** — `topicSlug` `2018-06-4mb1-01`…, `sectionSlug` `past-papers`, sourced from the SyllabAI pdflane archive (the set records say so in `source.provider`). They are NOT SME content and have no live RN bijection duty. Under the runtime null contract (`smeRowOfQuestionSet` returns null; spec-tree.ts:246: "the set keeps its official spine home") they keep their official homes — but a naive `smeActive` render would have emptied the EQ page: `smeAllRows` filters `count > 0`, and with zero resolving sets every SME row is 0 → `smeAllRows = []` → the whole question bank vanishes. The tranche-2 receipt's own warning ("a non-resolving set would vanish — the wave-3 bijection law prevents that") named exactly this hazard.

**The disclosed selector-code amendment** (the first of the wave-9 family — tranches 1–2 were zero-code): `exam-questions/page.tsx` gains the **smeMirror law** —

```
smeMirror = smeActive && smeAllRows.length > 0
```

- maths-a: mirror renders (58 topic sets 1:1) — unchanged behavior class vs tranches 1–2.
- maths-b: `smeMirror` false → the official EQ index renders exactly as before (its 65 papers grouped under the official spine + paper filter), while its NEW SME layer serves the /revision-notes selector (199 notes).
- the "Other sets" channel keys off **SME resolution under the mirror** (`placed` = sets with a non-null `smeRowOfQuestionSet`) so a future course with BOTH topic sets and official-home sets lists the latter honestly instead of hiding them — never hidden, never double-listed.
